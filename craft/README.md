# Craft
This is the booster the guidance system was developed and tested against.
To reproduce results, load in VAB, launch, and set position above launchpad at ~75km altitude.

## Game Version
Built in KSP 1.12.5, stock parts only, no DLC

## Craft Specs
- Part count: 17
- Mass: 80.320 t (wet), 16.320 t (dry)
- Height: 17.3 m
- Width: 3.4 m
- Length: 3.6 m
- Δv: 4,688 m/s (vacuum), 4,376 m/s (sea level)
- Max thrust: 2,000 kN (vacuum), 1,866.667 kN (sea level)
